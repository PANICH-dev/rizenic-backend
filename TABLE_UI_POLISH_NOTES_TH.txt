RIZENIC — Table UI Polish Patch

ขอบเขต: UI/Rendering ของตารางเท่านั้น ไม่เปลี่ยน API, Database, app.js, business logic,
filter/sort/search behavior, pagination data, edit/save หรือ export behavior

สิ่งที่แก้
1) SA Alerts
- Preview PO จาก 3 เหลือ 2 รายการต่อแถว เพื่อให้ความสูงแถวสม่ำเสมอขึ้น
- ข้อมูลทุก cell และปุ่ม "โต๊ะคีย์" ชิดด้านบนของแถว
- เอา display:block ออกจาก <td> PO ซึ่งผิดธรรมชาติของ table layout
- ย้าย scroll ตอน expanded ไปอยู่ inner list แทน TD
- ลด card ซ้อน: PO item ใช้เส้นแบ่งบางแทน border/shadow/rounded หลายชั้น
- ปุ่มดูเพิ่มเป็นปุ่มเล็ก "ดูเพิ่มอีก N รายการ" / "ย่อรายการ"
- Search SA Alerts เหลือ magnifier เพียงอันเดียว

2) Shared table polish ทุกหน้า interactive
- Header cell จัดกลางแนวตั้ง
- Body cell จัดชิดบน เพื่อไม่ลอยกลางเมื่อ row สูง
- Pagination มี safe padding ด้านล่าง/ขวา 10–12px
- ใช้ ui_global.css?v=1.1 เพื่อ cache-bust ทุกหน้า
- Inspection/print table ไม่ถูกแก้ เพราะเป็น layout เอกสารพิมพ์ ไม่ใช่ interactive table

3) Search icon consistency
- เอา emoji magnifier ซ้ำใน Jobs และ Repair ออกเมื่อมี Font Awesome icon อยู่แล้ว
